🚀 NETRA GCS - Rover Mission Control & Telemetry Station

NETRA GCS (Ground Control Station) is a futuristic web-based mission control platform designed for monitoring, controlling, and visualizing an autonomous exploration rover. The system provides a real-time telemetry dashboard, 3D rover visualization, tactical mission planning, sensor monitoring, power management, and multi-camera surveillance within a modern aerospace-inspired interface.

🌟 Features
🎮 Interactive rover control with keyboard and on-screen drive controls
🛰️ Real-time telemetry monitoring (speed, heading, battery, GNSS, power consumption)
🌍 Tactical mission map with waypoint navigation and route planning
🧭 Autonomous and manual driving modes
🚨 Emergency Stop (E-STOP) and safety controls
📡 Communication link and GNSS status monitoring
🎥 Multi-camera monitoring system (RGB, Thermal, Depth Vision)
🤖 3D Digital Twin Rover Visualization using Three.js
🔋 Battery and power distribution monitoring dashboard
📊 ROS2-inspired telemetry logging and diagnostics
🛠️ Configuration panel for rover parameters and safety limits
📱 Responsive and modern UI for easy operation and monitoring
🛠️ Technologies Used

🎯 Project Objective

The goal of NETRA GCS is to provide an intuitive and professional-grade Ground Control Station for planetary, research, and autonomous rover missions. It combines telemetry visualization, mission planning, robotics control, and sensor monitoring into a single unified platform.
